# Дизайн RAG-системы для поиска услуг салона красоты

## Обзор

Система состоит из двух основных компонентов: поискового модуля и консультационного модуля. Поисковый модуль использует облегченный файл для быстрого поиска, а консультационный модуль работает с полными данными для предоставления детальных ответов.

## Архитектура

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   Пользователь  │───▶│  Главный модуль  │───▶│   GPT Клиент    │
└─────────────────┘    └──────────────────┘    └─────────────────┘
                              │                          │
                              ▼                          ▼
                       ┌──────────────────┐    ┌─────────────────┐
                       │ Поисковый модуль │    │ Консультационный│
                       │                  │    │     модуль      │
                       └──────────────────┘    └─────────────────┘
                              │                          │
                              ▼                          ▼
                    ┌──────────────────┐    ┌─────────────────┐
                    │services_no_staff │    │   services.json │
                    │     .json        │    │                 │
                    └──────────────────┘    └─────────────────┘
```

## Компоненты и интерфейсы

### 1. Главный модуль (main.py)
- **Назначение**: Точка входа в приложение, координация работы модулей
- **Интерфейсы**: 
  - `start_chat()` - запуск интерактивного чата
  - `process_query(query: str) -> str` - обработка пользовательского запроса

### 2. GPT Клиент (gpt_client.py)
- **Назначение**: Взаимодействие с OpenAI API
- **Интерфейсы**:
  - `search_services(query: str, services_data: dict) -> List[str]` - поиск услуг
  - `generate_response(query: str, found_services: List[dict]) -> str` - генерация ответа

### 3. Поисковый модуль (search_module.py)
- **Назначение**: Поиск релевантных услуг в облегченном файле
- **Интерфейсы**:
  - `load_light_services() -> dict` - загрузка services_no_staff.json
  - `find_services(query: str) -> List[str]` - поиск и возврат ID услуг

### 4. Консультационный модуль (consultation_module.py)
- **Назначение**: Получение полной информации об услугах и генерация ответов
- **Интерфейсы**:
  - `load_full_services() -> dict` - загрузка services.json
  - `get_services_by_ids(service_ids: List[str]) -> List[dict]` - получение полных данных
  - `format_response(services: List[dict], query_type: str) -> str` - форматирование ответа

### 5. Конфигурационный модуль (config.py)
- **Назначение**: Управление настройками приложения
- **Интерфейсы**:
  - `load_config() -> dict` - загрузка конфигурации
  - `get_openai_key() -> str` - получение API ключа

## Обработка ошибок

### Типы ошибок:
1. **FileNotFoundError** - отсутствие файлов данных
2. **OpenAIError** - ошибки API OpenAI
3. **JSONDecodeError** - некорректный формат JSON
4. **KeyError** - отсутствие обязательных полей

### Стратегия обработки:
- Логирование всех ошибок
- Graceful degradation при недоступности GPT
- Валидация входных данных
- Информативные сообщения пользователю
