# Новая логика комбо-запросов

## Проблема старой логики
**СТАРАЯ:** категория1 + категория2 → выбор приоритета → услуга1 → запись1 → услуга2 → запись2
- ❌ Клиент может хотеть записаться в один день
- ❌ Неудобно планировать время
- ❌ Нет возможности согласовать расписание

## Новая улучшенная логика
**НОВАЯ:** категория1 + категория2 → услуга1 → услуга2 → выбор дат (один день/разные дни)

### Этапы:

1. **Распознать комбо**
   ```
   Пользователь: "маникюр и окрашивание"
   Бот: "Отлично! Давайте уточним обе услуги"
   ```

2. **Уточнить первую услугу**
   ```
   Бот: "1️⃣ Какой именно маникюр вас интересует?"
   Пользователь: "классический"
   ```

3. **Уточнить вторую услугу**
   ```
   Бот: "2️⃣ Какое именно окрашивание?"
   Пользователь: "сложное окрашивание"
   ```

4. **Планирование дат**
   ```
   Бот: "У нас есть:
   ✅ Классический маникюр
   ✅ Сложное окрашивание
   
   Хотели бы провести обе процедуры в один день или в разные дни?"
   ```

5. **Запись с учетом предпочтений**
   - Один день → подбор удобного времени для обеих процедур
   - Разные дни → отдельная запись на каждую процедуру

## Преимущества:

✅ **Полная картина** - клиент и салон понимают весь объем услуг  
✅ **Гибкое планирование** - можно записать в один день или разные  
✅ **Удобство клиента** - возможность согласовать расписание  
✅ **Эффективность салона** - оптимальное использование времени мастеров  

## Действия в системе:

- `ask_combo_services` - уточнить обе услуги в комбо
- `ask_combo_dates` - спросить про даты (один день/разные дни)

## Шаблоны:

- `ASK_COMBO_SERVICES` - пошаговое уточнение услуг
- `ASK_COMBO_DATES` - планирование дат для обеих процедур
